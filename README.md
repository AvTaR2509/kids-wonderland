# 🎈 Kids WonderLand - Kids PDF Worksheets & Activity Packs Marketplace

A complete marketplace and landing page built with **Next.js 16**, **Tailwind CSS**, and **Google Drive Cloud Storage** for selling printable kids activity books, worksheets, coloring books, and educational packs.

## 🌟 Key Features

- 🦁 **Fun Interactive Landing Page:** Animal Soundboard, Age Filters (Age 2-4, 4-6, 6-8), Kids Activity Bundle showcase.
- 🛍️ **Instant Checkout Flow:** UPI QR Pay, Buy Now modals with instant PDF unlock.
- 🔒 **Admin Dashboard (`/admin`):**
  - **Login:** Username: `admin` | Password: `admin123`
  - Upload worksheets with Hindi titles, age group, category, emoji, badge, price, and PDF files.
  - Automatic cloud upload to **Google Drive**.
- ☁️ **Serverless Ready:** Configured for Netlify serverless deployment without local file errors.
